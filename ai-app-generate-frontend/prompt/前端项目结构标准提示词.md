# 前端项目结构规范

请按照以下规范生成一个 Vue 3 前端项目的基础骨架（仅基础结构，不包含具体页面内容）。

---

## 一、技术栈

| 类别 | 技术选型 | 版本要求 |
|------|---------|---------|
| 框架 | Vue 3 | ^3.5 |
| 构建工具 | Vite | ^7.0 |
| 语言 | TypeScript | ~5.8 |
| UI 组件库 | Ant Design Vue | ^4.2 |
| 路由 | Vue Router | ^4.5 |
| 状态管理 | Pinia | ^3.0 |
| HTTP 请求 | Axios | ^1.13 |
| 日期处理 | Day.js | ^1.11 |
| BigInt 处理 | json-bigint | ^1.0 |
| SSE 支持 | event-source-polyfill | ^1.0 |
| 代码风格 | ESLint + Prettier | eslint ^9, prettier ^3.5 |
| API 代码生成 | @umijs/openapi (openapi2ts) | ^1.14 |

## 三、配置文件规范

### 3.1 Vite 配置 (vite.config.ts)
```typescript
import { fileURLToPath, URL } from 'node:url'
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'
import vueDevTools from 'vite-plugin-vue-devtools'

export default defineConfig({
  plugins: [
    vue(),
    vueDevTools(),
  ],
  resolve: {
    alias: {
      '@': fileURLToPath(new URL('./src', import.meta.url))
    },
  },
})
```

### 3.2 TypeScript 配置
- `tsconfig.json`：项目引用模式，引用 `tsconfig.node.json` 和 `tsconfig.app.json`
- `tsconfig.app.json`：继承 `@vue/tsconfig/tsconfig.dom.json`，路径别名 `@/*` → `./src/*`

### 3.3 ESLint 配置 (eslint.config.ts)
- 使用 Vue 官方 flat config 模式：`@vue/eslint-config-typescript` + `eslint-plugin-vue` + `@vue/eslint-config-prettier`
- 忽略 `dist/`、`dist-ssr/`、`coverage/`

### 3.4 Prettier 配置 (.prettierrc.json)
```json
{
  "semi": false,
  "singleQuote": true,
  "printWidth": 100
}
```

### 3.5 EditorConfig (.editorconfig)
- 缩进：2 空格
- 字符集：UTF-8
- 换行符：LF
- 行尾去空、末尾加空行

### 3.6 环境变量 (.env)
```
VITE_API_BASE_URL=http://localhost:8123/api
```
在 `env.d.ts` 中声明 `ImportMetaEnv` 类型接口，对环境变量做类型约束。

### 3.7 OpenAPI 代码生成 (openapi2ts.config.ts)
```typescript
export default {
  requestLibPath: "import request from '@/request'",
  schemaPath: 'http://localhost:8123/api/v3/api-docs',
  serversPath: './src',
}
```
用于根据后端 Swagger 文档自动生成 `src/api/` 下的请求函数和类型声明。

## 四、核心模块编码规范

### 4.1 应用入口 (main.ts)
```typescript
import { createApp } from 'vue'
import { createPinia } from 'pinia'
import App from './App.vue'
import router from './router'
import Antd from 'ant-design-vue'
import 'ant-design-vue/dist/reset.css'
import '@/access'  // 全局权限控制

const app = createApp(App)
app.use(createPinia())
app.use(router)
app.use(Antd)
app.mount('#app')
```

### 4.2 根组件 (App.vue)
- 使用 `<script setup lang="ts">` 组合式 API 语法
- 顶层包裹 `<a-config-provider :locale="zhCN">` 实现中文国际化
- 引入 dayjs 中文 locale
- 内部渲染 `BasicLayout` 组件

### 4.3 路由配置 (router/index.ts)
- 使用 `createWebHistory` 模式
- 路由 name 使用中文名称
- 按功能模块分文件存放页面组件，路径结构为：`/模块/操作`
  - 例：`/user/login`、`/admin/userManage`、`/app/chat`
- 静态导入所有路由组件（不使用动态加载）

### 4.4 Axios 封装 (request.ts)
- 创建独立 Axios 实例，从 `appConfig.ts` 读取 baseURL
- 配置 `timeout: 60000`、`withCredentials: true`
- 使用 `json-bigint`（storeAsString 模式）处理响应数据，防止 Long 类型精度丢失
- 请求拦截器：空拦截（预留扩展）
- 响应拦截器：统一处理 `code === 40100` 的未登录状态，自动跳转登录页并携带 redirect 参数

### 4.5 权限控制 (access.ts)
- 使用 `router.beforeEach` 全局前置守卫
- 首次加载时等待后端返回用户信息后再校验权限
- 以 URL 前缀判断权限：`/admin` 路径要求 `userRole === 'admin'`
- 无权限时跳转登录页并携带 redirect 参数

### 4.6 状态管理 (stores/)
- 使用 Pinia **组合式函数**风格（`defineStore('name', () => { ... })`），不使用 Option 风格
- `loginUser` store 约定：
  - `loginUser` ref 存储当前登录用户
  - `fetchLoginUser()` 从后端获取用户信息
  - `setLoginUser()` 更新用户信息

### 4.7 应用配置 (config/appConfig.ts)
- 从环境变量读取基础 URL，提供默认值兜底
- 提供 URL 工具函数：`buildApiUrl`、`joinUrl`、`normalizeUrl` 等
- 统一处理 URL 尾部斜杠

### 4.8 布局 (layouts/BasicLayout.vue)
- 使用 Ant Design Vue 的 `<a-layout>` 组件
- 结构：`<GlobalHeader>` + `<a-layout-content><router-view /></a-layout-content>` + `<GlobalFooter>`
- 简洁布局，content 无额外 padding

### 4.9 全局头部 (components/GlobalHeader.vue)
- 使用 `<a-layout-header>` + `<a-row>` 三栏布局（Logo | 菜单 | 用户操作）
- 菜单配置：定义 `originItems` 数组，通过 `computed` 动态过滤（如根据角色过滤 admin 菜单）
- 菜单项使用 `mode="horizontal"` 水平模式
- 路由变化时通过 `router.afterEach` 同步选中菜单项
- 用户区域：已登录显示头像+下拉菜单（退出登录），未登录显示登录按钮

### 4.10 API 层 (api/)
- 由 openapi2ts 自动生成，**不手动编写**
- 类型声明集中在 `typings.d.ts`，使用 `declare namespace API` 命名空间
- 每个 Controller 对应一个 `*Controller.ts` 文件
- 请求函数统一签名：`export async function xxx(params, options?) => return request<T>(...)`
- `index.ts` 统一导出所有 Controller

## 五、页面组件编码习惯

### 5.1 Vue 组件通用规范
- **一律使用 `<script setup lang="ts">` 组合式 API**，不使用 Options API
- 组件结构顺序：`<template>` → `<script setup lang="ts">` → `<style scoped>`
- 样式使用 `<style scoped>`，页面根元素以 `id="xxxPage"` 命名

### 5.2 表单页面
- 使用 Ant Design Vue 的 `<a-form>` 组件
- 表单数据使用 `reactive()` 响应式对象
- 表单校验使用 `<a-form-item>` 的 `:rules` 属性
- 提交使用 `@finish` 事件

### 5.3 管理表格页面
- 搜索表单：`<a-form layout="inline">`，搜索按钮 `html-type="submit"`
- 表格：`<a-table>` + `columns` 配置数组 + `computed pagination`
- 分页参数放在 `searchParams` reactive 对象中（pageNum、pageSize）
- 通过 `@change` 事件处理分页/排序变化
- 数据加载在 `onMounted` 中触发
- 操作成功/失败使用 `message.success/error` 提示
- 日期格式化使用 `dayjs(time).format('YYYY-MM-DD HH:mm:ss')`
- 删除等操作后调用 `fetchData()` 刷新列表

### 5.4 API 调用习惯
- 从对应的 Controller 文件按需导入：`import { xxx } from '@/api/xxxController'`
- 统一通过 `res.data.code === 0` 判断成功
- 错误信息拼接：`message.error('操作失败，' + res.data.message)`
- 捕获异常：`try/catch` 包裹异步调用，catch 中 `message.error('操作失败')`

## 六、工具函数规范 (utils/)
- `id.ts`：统一 ID 类型处理
  - `IdLike` 类型别名（`string | number | bigint | null | undefined`）
  - `normalizeId(id)` 归一化为字符串
  - `normalizeRouteId(value)` 处理路由查询参数中的 ID
  - `isSameId(left, right)` 安全比较两个 ID
